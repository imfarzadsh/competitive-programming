## 🛠️ Naming Conventions

- **File Format:** `[Index]-[ProblemID]-[ProblemName].cpp` (e.g., `0001-1068-WeirdAlgorithm.cpp`)
- **Problem ID:** The unique 4-digit number assigned by CSES (e.g., `1068`).
